# Results

Generated by `python -m wtsurrogate.cli pipeline`. Every number below comes from that run. The data is produced by the BEM solver in this repository with an illustrative rotor and approximate polars. It is not CFD data and not the data of the author's paper. Timings depend on the machine.

## Dataset

- Latin hypercube design, seed 0: 1500 BEM runs, 0 dropped for non-convergence, 1500 kept
- BEM wall time for the whole design: 0.35 s (vectorised)
- split: 1050 train, 225 calibration, 225 test
- Cp range in the dataset: -0.197 to 0.485
