# Software Installation Rules

## Software catalogue
Approved applications are installed from the self-service software catalogue without administrator rights. The catalogue lists about 200 applications.

## Requesting new software
Software that is not in the catalogue is requested with a ticket. The security team checks the licence terms and the vendor within 10 working days. Browser extensions follow the same process.

## Prohibited software
Peer-to-peer file sharing tools, remote access tools that were not issued by IT and unlicensed software are prohibited. Local administrator rights are granted for a maximum of 4 hours through the privilege elevation tool and every use is logged.
