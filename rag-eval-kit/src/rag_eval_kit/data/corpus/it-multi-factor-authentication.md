# Multi-Factor Authentication

## Where it applies
A second factor is mandatory for every sign-in from outside the office network and for all administrator accounts everywhere.

## Allowed factors
Allowed methods are the authenticator app with number matching and FIDO2 security keys. Text message codes and voice calls are not allowed because they can be intercepted.

## Lost device
If the phone with the authenticator app is lost, the employee calls the service desk. After identity verification a temporary access pass valid for 8 hours is issued so that a new device can be registered. Administrators must own two security keys.
