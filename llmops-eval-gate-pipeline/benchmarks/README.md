# Benchmarks

All data in this directory is synthetic.

| File | Purpose |
| --- | --- |
| `intent_benchmark.jsonl` | 400 synthetic support tickets (`id`, `text`, `label`), generated by `examples/make_benchmark.py` with seed 42 |
| `gates.yaml` | Evaluation gates for the ONNX intent classifier |
| `prompt_gates.yaml` | Evaluation gates for prompt versions |
| `alert_rules.yaml` | Drift alert thresholds used by `llmops monitor` |
| `baseline_metrics.json` | Reference metrics the CI eval gate compares a candidate against |

Tickets are bags of words drawn from per-intent vocabularies. With the default keyword noise of
0.3, each intent keyword is replaced by a keyword of another intent with probability 0.3, so no
classifier can reach 100 percent.
